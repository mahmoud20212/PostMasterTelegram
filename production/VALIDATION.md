# حالة التحقق قبل النشر

- اختبارات المشروع على SQLite: 179 إجمالًا؛ 173 نجحت و6 خاصة بـPostgreSQL جرى تخطيها.
- اختبارات المشروع على PostgreSQL: 179 نجحت.
- تتضمن النتائج 13 اختبارًا لإعداد الإنتاج: الأسرار، رفض الكتابة فوق الإعداد، TLS، النسخ والاستعادة،
  تحقق Compose الحقيقي، وفحص إدارة Django والملفات الثابتة وتحويل HTTPS دون اتصال بقاعدة حقيقية.
- تحقق `uv lock --check --offline` نجح دون تغيير lockfile أو تنزيل اعتماديات جديدة.
- تحقق الترحيلات لم يجد تغييرات. فحوص صياغة Python وملفات shell والمسافات نجحت.
- جرى تحديث توقعات ثلاثة اختبارات للترحيب لتطابق الفاصل `|` الموجود أصلًا في الواجهة؛ لم يتغير نص الواجهة.

## ما لم يُتحقق منه بعد

أصبح الوصول إلى Docker ممكنًا خارج قيود الجلسة، وبدأ بناء الصور في مشروع اختبار عشوائي معزول.
كان تنزيل الصور بطيئًا جدًا، فأُوقفت محاولة البناء بطلب المستخدم لتأجيلها إلى الـVPS.
أُوقفت عمليتا عميل البناء التابعة للاختبار، ونُظّف مجلد الاختبار المؤقت. لم تبدأ حاويات الاختبار؛
لا توجد حاويات باقية لذلك المشروع. قد تبقى طبقات صور عامة في cache، ولم تُحذف صور المستخدم.

**لا يُعد البناء أو اختبار الحاويات ناجحًا بعد.** لم تُصدر شهادة Let's Encrypt فعلية، ولم يُنفّذ
اختبار تجديد/إعادة تحميل Nginx أو بقاء البيانات داخل الحاويات. هذه الفحوص موجودة في harness:

```sh
python3 -m production.smoke --build
```

يجب تشغيله على الـVPS قبل اعتماد الإعداد، ثم تجربة تحدي ACME العام على IP الخادم وفق الدليل.
الفحص يستعمل مشروعًا مستقلًا وشهادة اختبار محلية وTelegram مُحاكى؛ لا يشغّل البوت الحقيقي.
لم تتغير قواعد البيانات المحلية أو مفاتيحها، ولم تُوقف أو تُعد تشغيل خدمات البوت الحالية.
